# Storytelling
Start with the audience's question. Write slide headlines as conclusions, not labels. Typical narrative: hook → context → problem → evidence → solution → implementation → implications → close. Adapt freely for teaching and research. Make each slide answer one question and lead to the next. Explain jargon on first use. End with a takeaway or decision. Do not manufacture data.

## Cross-reference: color system
Follow `color-psychology.md` (Johannes Itten, *The Art of Color*): choose a named contrast strategy, keep semantic color roles stable, and verify contrast. Do not infer unsupported psychological effects from hue.
