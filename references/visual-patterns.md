# Visual composition patterns
Use a consistent grid and safe margins. Establish one focal point per slide.

- Contrast: distinguish key takeaway from evidence using size, weight, and spacing.
- Alignment: align titles, cards, charts, and labels to a visible grid.
- Proximity: group related elements; separate unrelated ideas.
- Repetition: keep typography, accent role, spacing, and chart semantics consistent.
- Negative space: allow ideas to breathe; split overcrowded slides.
- Progressive disclosure: arrange process slides in reading order.
- Gestalt: use grouping and continuity to show relationships, without decorative clutter.
- Data-ink discipline: remove chart ornamentation that does not convey data.
- Accessibility: never encode meaning with color alone; label diagrams and charts.

Pattern selection: process -> steps; comparison -> two columns; evidence -> chart; statement -> quote; KPI -> metrics; detailed explanation -> bullets.
V2 scripts support these native patterns; sophisticated freeform illustration and automatic visual QA remain future work.

## Cross-reference: color system
Follow `color-psychology.md` (Johannes Itten, *The Art of Color*): choose a named contrast strategy, keep semantic color roles stable, and verify contrast. Do not infer unsupported psychological effects from hue.
